# The node runtime's direct dependencies, pinned to the versions the working
# venv (nodes/.venv, Python 3.14) was built with.
#
# This is deliberately not a `pip freeze`: it lists only what the code imports
# (plus lap, which ultralytics does not declare but model.track() needs) so a
# version bump here is a decision rather than a dump. pyproject.toml carries the
# same packages as abstract lower bounds and is the authoritative list; keep the
# two in step.
#
#   python3 -m venv nodes/.venv
#   nodes/.venv/bin/pip install -r nodes/requirements.txt
#

# GStreamer, and the typelibs) -- pip only builds the bindings.
